Katalon Studio — Petstore API Automation (Layered Architecture)

Proyek API automation testing untuk petstore.swagger.io/v2 menggunakan Katalon Studio + Groovy dengan arsitektur berlapis (Layered Architecture): Test Suite → Scenario → Step → Helper. Mencakup 20 skenario untuk 3 service (Pet, Store, User) dengan dua mode eksekusi: per-service dan End-to-End (PET-10).

Arsitektur Berlapis (Layered Architecture)

Keunggulan utama project ini adalah pemisahan tanggung jawab yang jelas antar layer:

Layer 1 — Test Suite
Local Test Suite.ts — Entry point. Description diisi PET-10,sit / pet,sit / store,sit / user,sit untuk menentukan mode eksekusi.
Layer 2 — Scenarios (Test Cases/Scenarios/)
Test case level bisnis. Setiap scenario memanggil executePreTest, executeMainTest, executePostTest. Contoh: add new pet with status available, TC010-Pet-Full-Lifecycle-Flow.
Layer 3 — Steps (Test Cases/Steps/Service/)
Test case level teknis/API. Setiap step memanggil satu operasi API spesifik: pet/pet, pet/find-by-status, store/store, store/inventory, user/user, user/login, dll.
Layer 4 — Helpers (Include/scripts/groovy/)
ApiHelper.groovy — kirim HTTP request, log request/response
Context.groovy — state global (baseUrl, carryOver, datatest)
ExtentReport.groovy — generate HTML report
Validate.groovy — assertion: assertEqual, assertNotNull
Logger.groovy — log INFO/PASS/FAIL/ERROR

Carry-Over State

Data yang dihasilkan satu step dipakai step berikutnya via Context.carryOver, di-reset setiap AfterTestCase:

add new pet    → Context.putCarryOver(["petId": "12345"])
get pet by id   → Context.getCarryOver("petId") // "12345"
update pet     → Context.getCarryOver("petId") // "12345"
delete pet     → Context.getCarryOver("petId") // "12345"

place order    → Context.putCarryOver(["orderId": "67890"])
get order by id → Context.getCarryOver("orderId") // "67890"

create user    → Context.putCarryOver(["username": "john_doe"])
get user       → Context.getCarryOver("username") // "john_doe"

Cara Menjalankan

  1. Clone repo:
    git clone https://github.com/hardisahrulaj/petstore-katalon.git
  2. Buka Katalon Studio → File → Open Project → pilih folder petstore-katalon
  3. Buka Profiles → local, pastikan baseUrl = https://petstore.swagger.io/v2
  4. Buka Test Suites → Local Test Suite → tab Information → isi Description:
    pet,sit (Pet saja)  |  store,sit (Store saja)  |  PET-10,sit (E2E semua)
  5. Klik Run ▶ — laporan HTML otomatis dibuat di Reports/<timestamp>/Local Test Suite/
