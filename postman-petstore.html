Postman + Newman — Petstore API Automation (CASE02)

Proyek API testing untuk petstore.swagger.io/v2 menggunakan Postman Collection dengan request chaining via environment variables, randomized ID generation, dan CLI execution via Newman dengan HTML & JSON reporting.

Cara Menjalankan Test (Newman CLI)

1. Install dependencies:

npm install -g newman newman-reporter-htmlextra

2. Verifikasi:

newman --version

3. Generate semua report sekaligus (rekomendasi):

newman run petstore_collection.json -e petstore_environment.json -r cli,htmlextra,json --reporter-htmlextra-export reports/report.html --reporter-json-export reports/report.json

Buka reports/report.html di browser untuk melihat hasil lengkap.
