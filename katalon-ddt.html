Katalon Studio — UI Automation with Data Driven Test (DDT)

Proyek automation testing untuk demoqa.com/automation-practice-form menggunakan Katalon Studio dengan metode Data Driven Test (DDT). Semua 9 skenario dijalankan otomatis dari satu file CSV.

Detail step, expected result, dan actual result tersedia di file Test Case Design - Student Form.xlsx.

Cara Menjalankan Test

  1. Buka Katalon Studio v9.6.0
  2. Pilih Open Project → arahkan ke folder Automation-Katalon
  3. Di panel Test Explorer, buka folder Test Suites
  4. Klik dua kali file StudentFormDDTSuite
  5. Pastikan checkbox Run pada TC_StudentForm_DDT sudah dicentang
  6. Klik tanda panah (▼) di samping tombol Run → pilih Chrome
  7. Test berjalan otomatis untuk semua 9 baris data dari Student Data Scenario.csv

Cara Generate Report

Export PDF:

  1. Klik tab Test Explorer (ikon file hijau)
  2. Buka folder Reports → pilih folder YYYYMMDD_HHMMSS terbaru
  3. Buka folder StudentFormDDTSuite → klik file timestamp
  4. Klik tombol Export Report (kanan atas) → pilih format PDF

Report XML (JUnit): File JUnit_Report.xml otomatis tersedia di:

Reports/YYYYMMDD_HHMMSS/StudentFormDDTSuite/YYYYMMDD_HHMMSS/JUnit_Report.xml
